# 来源契约

GET /xapi/statements 支持 since（stored严格大于）、until（stored小于等于）、attachments=true、statementId 与 voidedStatementId。语句页有 statements 和 more；more 为来源相对地址，保留原查询。每页最多两条，读取more时不能改变查询。X-Experience-API-Version 为1.0.3，X-Experience-API-Consistent-Through为来源确认已经完整可见的stored边界。
语句id是不可变身份；timestamp是活动发生时间，stored是入库时间。actor均是本地合成账号，context标注项目。verb的voided语句通过StatementRef指向目标，允许目标尚未到达。statementId不返回已被作废的s-late原文，voidedStatementId可查原文。
attachments=true 返回标准MIME multipart/mixed，首部分是JSON，其后是二进制，使用X-Experience-API-Hash关联sha2。同摘要只随附一次；fileUrl为授权材料地址，附件声明含length/contentType/sha2。地址按响应来源解析。不同语句可以共用摘要，文件名不是身份。GET /files/<sha2>在发布前返回503，材料可取时返回原始字节；corrupt控制项可模拟摘要不符。
阶段0含先到的void-1及s-2、s-3；阶段1补入事件时间很早但stored较晚的s-late；阶段2开放其材料。consistent-through分别为10:00:03Z、10:00:04Z。资料时间日期均为2026-11-16，事件timestamp另有明确值。

演练控制：POST /__control 接收JSON stage及上述控制项，GET /__log显示请求观测；它们供资料源演练与来源测试使用，不属于业务资料获取接口，不得用其直接生成采集结果。每次启动是独立状态。GET /health仅检查服务可用性。
